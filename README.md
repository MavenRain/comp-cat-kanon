# comp-cat-kanon

Computational category theory in native Kanon, ported from
[comp-cat-ocaml](https://github.com/MavenRain/comp-cat-ocaml) at
`426b28a1cff7b3af27be8b941465b2f19a1e7677`.

The library implements finite Kan extensions and their universal maps, finite
limits and colimits, adjunctions, omega constructions, finite sets and graphs,
Kleisli substitutions and unification, classifiers and exponentials, symbolic
theories, and temporal logic over streams and lassos. It compiles to WebAssembly
GC. Mathematical implementations are `.kan` sources; Node runs the tests.

## Build and test

Requirements: Python 3, Git, tar, patch, OCaml, Dune 3.24 or newer, Zarith 1.14,
and Node 22 or newer with WebAssembly GC support. There are no npm dependencies.

```sh
python3 scripts/bootstrap.py
npm test
```

Bootstrap builds a pinned Kanon revision in the ignored `.toolchain` directory
and applies the bundled constructor elaboration patch. An existing Kanon
checkout can supply the sources without downloading them:

```sh
python3 scripts/bootstrap.py --source ../kanon
```

That checkout is read-only. The patch admits explicitly annotated, unindexed
parameterized constructors while retaining kernel type validation. Tests check
constructor acceptance and rejection of an incorrect field type. See
[toolchain/lock.json](toolchain/lock.json).

## Use the library

`modules.json` specifies the source order. The build script supplies those files
before your program:

```sh
node scripts/build.mjs examples/finite.kan -o build/example.wasm --export exampleCardinality
node scripts/run-export.mjs build/example.wasm exampleCardinality
```

The example computes a coproduct through the Kan extension engine and prints
`4`. Fallible operations return `Result`; callers can inspect the structured
`Error` or render it with `errorText`.

Categories are typed dictionaries. `Category O H` contains name, source, target,
identity, composition, object equality, arrow equality, object renderer, and
arrow renderer. `c.4 g f` computes `g ∘ f`.

`Grounding O H` contains the category, an initial object, coproducts, and
coequalizers, including their universal maps. Supply an opposite grounding to
`ran`, `limit`, or derived products, equalizers, and pullbacks.

See [API.md](API.md) for the source map and [PORTING.md](PORTING.md) for
representation choices and behavioral boundaries.

## Reference checks

Tests compare Kanon outputs with 324 observations generated by the pinned OCaml
source. Regenerate them in an isolated archive with:

```sh
python3 scripts/oracle.py --source ../comp-cat-ocaml --switch comp-cat-ocaml
```

The switch argument is optional when the OCaml dependencies are already active.
The source checkout remains untouched. See [VALIDATION.md](VALIDATION.md).

Refresh generated source files with:

```sh
python3 scripts/literals.py
python3 scripts/temporal_constructors.py
python3 scripts/theory_constructors.py
python3 scripts/differential.py
```

For an explicitly supplied patched compiler, set `COMP_CAT_KANON_ROOT` and
`COMP_CAT_KANON_BIN`. `KANONCHO` optionally selects a compact compiler reporter.
